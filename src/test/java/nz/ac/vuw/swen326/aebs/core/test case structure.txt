TEST CASE: test case number/req ID + small title
PRE: preconditions before running test
STEPS: actions used to perform test
EXPECT: expected outcome

tests are done to test whether expected outcomes are met or not. if they are met then that test counts as passed, if not then there will need to be adjustments to the simulation
